# [Project] 2026학년도 교사 주간 시간표 & 교사 비교 시스템

2026학년도 2학기 학교 시간표 엑셀 데이터 및 3학년 당겨오기 수업 계획을 파싱하여 주간 시간표를 시각화하고, 교사 간 빈 시간(공강) 비교(Split-View), 동시 공강 자동 분석 및 **마지막 확인 장면 기억(상태 지속성)**을 제공하는 올인원 정적 웹 애플리케이션(SPA)입니다.

---

## 🌟 주요 기능

### 1. 💾 마지막 확인 장면 자동 기억 및 복원 (State Persistence)
- 브라우저를 닫거나 새로고침하더라도 사용자가 마지막으로 조회했던 상태를 완벽히 기억하고 복원합니다:
  - **마지막 활성화 탭** (`주간 시간표` 또는 `교사 비교`)
  - **마지막 선택 주차** (예: `2주차: 8/24 ~ 8/28`)
  - **마지막 조회 교사** (단일 시간표의 특정 교사명)
  - **마지막 비교 교사 A & B** (비교 모드에서 선택했던 교사 2인)
- 복원 시 `"마지막으로 확인했던 화면(...)을 복원했습니다."` 안내 알림을 제공합니다.

### 2. 📅 2026학년도 2학기 주간 시간표 및 3학년 당겨오기 자동 병합
- **2026년 2학기 달력 기반 주차 제어**:
  - 개학 주차(2026년 8월 17일)부터 종업 주차까지 주차별(`<`, `>`) 및 오늘 주차 이동 지원
  - 요일별 실제 날짜 표시 (`8/17(월)`, `8/18(화)` 등)
- **3학년 당겨오기 수업 스마트 오버레이**:
  - 선택한 주차의 화7, 수5, 목7 등 당겨오기 지정 날짜에 원래 요일/교시의 수업(예: `월6`, `화5`)을 자동 추적하여 시간표에 주황색 배지(`⚡ 당겨옴: 월6`) 및 툴팁과 함께 병합 출력
  - 특별 행사(학력평가, 1차 정기시험, 추석연휴, 수능 등) 안내 배지 자동 표기
- **교사 선택 & 메타데이터 요약**:
  - 60명 교사명 가나다순 정렬 드롭다운
  - 주당 시수 및 담임 학급 배지 제공
- **인쇄 기능 지원**:
  - `[🖨️ 인쇄하기]` 원클릭으로 주간 시간표를 깔끔하게 출력

### 3. 👥 교사 시간표 비교 (Split-View)
- **2인 분할 비교 뷰**:
  - 교사 A와 교사 B를 선택하여 좌우 분할 화면으로 시간표 동시 비교
- **상호 동시 공강(Free Period) 자동 분석**:
  - 두 교사 모두 수업이 없는 교시를 초록색(`★ 동시 공강`)으로 강조
  - "총 N시간 동시 공강 (추천 회의/협의 시간: 화3, 목4...)" 상단 요약 카드 제공

### 4. 📂 엑셀 파일 관리 및 100% 클라이언트 사이드 동작
- SheetJS(`xlsx.full.min.js`) 내장으로 **완전한 오프라인 작동** (외부 API 0원, 보안 유지)
- 실제 2026학년도 2학기 시간표 및 3학년 당겨오기 계획 데이터가 기본 내장되어 있어 실행 즉시 사용 가능
- 새로운/수정된 엑셀 파일 드래그 앤 드롭 업로드 및 실시간 파싱 지원

## 🚀 실행 및 배포 방법

### 1. 로컬(Local) 환경에서 실행
- 별도의 Node.js나 백엔드 웹서버 설치 없이, **`index.html` 파일을 크롬이나 엣지 등 웹 브라우저에서 더블 클릭**하여 즉시 실행할 수 있습니다.

### 2. GitHub Pages 무료 웹 호스팅 배포
1. 본 프로젝트 폴더를 Git 저장소로 초기화하고 GitHub 원격 리포지토리에 푸시합니다:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Teacher Timetable & Comparison System"
   git branch -M main
   git remote add origin https://github.com/{사용자이름}/{저장소이름}.git
   git push -u origin main
   ```
2. GitHub 저장소 페이지의 **Settings > Pages** 메뉴로 이동합니다.
3. **Branch**를 `main`, 폴더를 `/(root)`로 지정하고 **Save**를 누릅니다.
4. 1~2분 후 제공되는 URL (`https://{사용자이름}.github.io/{저장소이름}/`)로 접속하면 웹으로 이용 가능합니다.
